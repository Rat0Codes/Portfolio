# 💻 Rudson Santos — Portfólio

> Meu espaço na web para apresentar minha jornada, projetos e experimentos em tecnologia.

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades, interesses e evolução como estudante de Engenharia da Computação e desenvolvedor em formação.

O portfólio funciona como uma espécie de laboratório pessoal: um lugar para mostrar o que estou construindo, testar novas ideias e registrar minha evolução na área de tecnologia.

## 🚀 Sobre o projeto

O objetivo deste projeto é criar uma experiência simples, moderna e interativa para apresentar:

* 👨‍💻 Sobre mim
* 🛠️ Tecnologias e habilidades
* 📂 Projetos
* 🎓 Formação
* 🧭 Minha jornada
* 🧪 Experimentos e projetos em desenvolvimento
* 🏆 Conquistas
* 📫 Formas de contato

Além de servir como apresentação profissional, o próprio portfólio também é um projeto em constante evolução.
